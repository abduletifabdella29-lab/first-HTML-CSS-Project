## 📖 About This Project

This landing page was built as my introduction to front-end web development. The goal was to practice:

- Structuring a webpage with semantic HTML
- Styling with plain CSS (no frameworks)
- Building layouts with **Flexbox**
- Making a design **responsive** across desktop, tablet, and mobile screen sizes
- Adding simple interactivity through hover states and transitions

It's not meant to be a polished final product — it's a record of what I learned as a beginner, and a base I plan to keep improving as I learn more.

## ✨ Features

- Sticky header with navigation and a call-to-action button
- Hero section with a heading, intro text, and two action buttons
- Responsive hero image that:
  - Shows full-size on large screens
  - Shrinks on medium/tablet screens
  - Hides on small/mobile screens to keep things clean
- "My Services" section with three service cards
- "Recent Projects" image gallery
- Hover animations on cards, images, and buttons
- Fully responsive layout (mobile, tablet, and desktop breakpoints)

## 🛠️ Built With

- **HTML5** — page structure
- **CSS3** — styling, Flexbox layout, media queries, transitions

No frameworks or libraries — everything is written from scratch to practice the fundamentals.

   ```bash

   ```
2. Open the folder in VS Code.
3. Install the **Live Server** extension (if you don't have it).
4. Right-click `index.html` → **Open with Live Server**.

That's it — no build tools or dependencies needed.

## 📚 What I Learned

- How Flexbox controls layout direction, wrapping, and alignment
- How to use media queries to adapt a design for different screen sizes
- Why `box-sizing: border-box` and resets (`* { margin: 0; padding: 0; }`) matter
- How small details (like `align-items`, `flex-basis`, and image aspect ratios) affect a layout more than expected
- The importance of testing a design at multiple screen widths, not just one
